# 手机访问指南

在手机上随时随地查看「个人工作台」，一共三步：**组网（Tailscale）→ 打开网页 → 添加到主屏幕**。首次配置后再也不用动。

## 原理

工作台运行在你自己的电脑上（默认端口 `52342`）。手机通过 Tailscale 组成的加密私有网络访问电脑，不出家门、走流量也能打开；只有登录过你 Tailscale 账号的设备才能连入，外部人无法访问。

> 前提：手机访问时电脑需要开机且工作台正在运行（见下文「保持电脑随时可达」）。

## 第一步：安装 Tailscale（一次性）

1. 电脑：打开 <https://tailscale.com/download> 下载 Windows 版，安装后登录（可用 Google / Microsoft / Apple / GitHub 账号注册，免费套餐够个人用）。
2. 手机：在应用商店（App Store / 各大安卓商店）安装 Tailscale，用**同一个账号**登录。
3. 手机上打开 Tailscale 开关（Connected 状态）。

## 第二步：在手机上打开工作台

1. 先在电脑上确认工作台已启动（双击「启动个人工作台」后浏览器能正常打开）。
2. 查询电脑的 Tailscale 地址：在电脑 PowerShell 里执行
   ```powershell
   tailscale ip -4
   ```
   会得到类似 `100.x.y.z` 的地址（前提：安装 Tailscale 时勾选了命令行工具；装完没有的话重开一个 PowerShell 窗口）。
3. 手机浏览器（推荐 Safari / Chrome）访问：
   ```
   http://100.x.y.z:52342
   ```
4. 首次打开会要求设置**访问密码**（在「设置 → 访问密码」里也可以改）。登录一次后 180 天内免输密码。

> 手机上打不开？按顺序排查：
> ① 电脑端工作台是否在运行（浏览器本机打开 `http://127.0.0.1:52342/health` 应显示 JSON）；
> ② 手机 Tailscale 是否为 Connected；
> ③ 电脑 Windows 防火墙：第一次启动时如弹出「是否允许 Node.js 访问网络」请点允许；也可以手动放行——「Windows 安全中心 → 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 52342 允许」。

## 第三步：添加到主屏幕（像 App 一样用）

- **iPhone（Safari）**：打开工作台 → 点底部中间「分享」按钮 → 往下滑点「添加到主屏幕」→ 确认。图标名称显示为「工作台」。
- **Android（Chrome）**：打开工作台 → 右上角菜单 → 「添加到主屏幕」/「安装应用」。

添加后从主屏幕图标打开就是全屏界面，和原生小程序体验一致。

## 保持电脑随时可达

- **别让电脑睡觉**：设置 → 系统 → 电源 → 「接通电源时，将设备置于睡眠状态」改为**从不**（笔记本合盖也可以在电源选项里设为「不采取任何操作」）。
- **开机自动启动工作台**：`Win + R` 输入 `shell:startup` 回车，把「启动个人工作台」的快捷方式放进去。开机登录后自动拉起服务。
- **电脑关机/重启后**：Tailscale 会自动连上；工作台随自启动恢复，无需任何手动操作。

## 离线时能看什么

工作台内置了 PWA 离线缓存：手机断网或弱网时，应用外壳和**最近浏览过的数据**仍可查看（只读），恢复联网后自动回到最新数据。新录入仍需联网。

## 安全说明

- 访问密码：散列（scrypt）后存放在本机数据库 `data/workbench.sqlite`，不会上传；登录会话有效期为 180 天；修改密码会让所有其他设备下线。
- 传输链路：Tailscale 端到端加密（WireGuard），明文 HTTP 不会暴露到公网。
- 若想临时收紧：直接退出电脑上的 Tailscale，手机立即无法访问。
