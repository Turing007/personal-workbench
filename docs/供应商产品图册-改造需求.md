# 供应商产品图册 · 改造需求

## 1. 背景与目标

现在「产品图册」里只有我方生成的在线图册。供应商通过微信、邮件发来的 PDF / 图片图册散落在聊天记录里，找起来费劲，也没法按供应商统一翻。

新增一个内部资料库「供应商产品图册」：把供应商发来的图册文件按供应商归档，能搜索、预览、下载，不再依赖聊天记录。

## 2. 入口与页面

在「产品图册」页顶部增加两个页签：

- **我的图册**：现有在线链接图册，保持原样。
- **供应商图册**：新增，用来收集供应商发来的资料。

供应商图册页签内：

- 顶部：搜索框（按供应商 / 图册名 / 文件名搜）、「上传供应商图册」按钮。
- 下面按收到日期倒序排列卡片；手机端单列，不横向溢出。
- 卡片显示：供应商名称、图册名称、收到日期、文件数量与总大小、备注；每个文件一行，带打开、下载、删除。

## 3. 一条「供应商图册」包含什么

| 字段 | 规则 |
|---|---|
| 供应商名称 | 必填，手输；输入时可点已有产品里的供应商名快速填入 |
| 图册名称 | 必填，默认取第一个文件名，可改 |
| 收到日期 | 默认今天，可改 |
| 备注 | 可选，例如“2026 新品报价”“只含电钻” |
| 附件 | 一条记录 1~20 个文件；PDF / PNG / JPG / WebP；单个不超过 20MB |

一条记录可以放多个文件，是因为供应商经常一次发来“总册 PDF + 几张细节图”，归在同一条里比拆成多条好找。

## 4. 上传与编辑

- **新建**：弹窗填写供应商、图册名称、收到日期、备注，选择多个文件；保存时先建记录，再逐个上传附件。
- **上传方式**：支持点选、拖入，以及直接 Ctrl+V 粘贴 PDF / 图片；粘贴在弹窗内任意位置都生效，不需要先点中上传区。
- **追加文件**：编辑已有记录时可以继续添加文件，也可以删除单个文件。
- **删除整条**：二次确认；记录和所有附件一起删除，不能恢复。
- **失败处理**：某个文件上传失败时，已成功的文件保留，弹窗里明确提示是哪个文件失败；再次点「保存」会重试失败的文件。

## 5. 存储、安全与备份

- 新增数据表：`supplier_catalogs`、`supplier_catalog_files`，数据库版本升到 38。
- 文件存放在 `data/files/supplier-catalogs/`，和现有附件一起进备份 ZIP。
- 仅登录用户可访问；供应商图册不生成客户链接，公网不可见。
- 备份恢复后，供应商图册记录与文件都要还在。

## 6. v1 不做

- 不自动识别 PDF 里的产品，也不导入产品库。
- 不做 PDF 首页缩略图，先用 PDF 文件图标。
- 不新建供应商主数据，供应商名按手输保存。
- 不做供应商图册的外部分享链接。

## 7. 验收标准

- 能上传多个 PDF / 图片，归成一条供应商图册。
- 列表能按供应商、图册名、文件名搜索。
- 文件能在新标签打开、下载；删除记录后文件不可再访问。
- 编辑记录能改信息、追加文件、删除单个文件。
- 手机端单列卡片，无横向溢出。
- 备份恢复后记录和文件都完整。

## 8. 待确认（默认按下面执行）

1. **文件范围**：只收 PDF 和图片，单个 20MB，一条最多 20 个文件。需要收 PPT、ZIP 或更大单文件，请直接说。
2. **预览方式**：点文件在新标签打开，PDF 用浏览器自带阅读器；不另做应用内预览。若手机 App 里必须直接看 PDF，需要另做。
3. **供应商名**：手输，输入框下方给出已有产品供应商的快捷胶囊，不建供应商档案。

确认以上默认口径后开始实现。
