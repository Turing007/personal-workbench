# 报价单与销售开单设计规格

## 目标

在现有个人工作台中增加两个完全独立的业务模块：

1. **报价单**：客户前期咨询时，从系统产品库调用产品图片、品名、SKU、规格等资料，填写数量和报价价格，生成 A4 纵向报价单 PDF 发给客户。
2. **销售开单**：按现有 Excel 样式制作独立销售单，既可以从系统产品库调用产品，也可以添加当前单据专用的临时产品；支持收款记录、付款凭证、未付款金额计算和 PDF 导出。

报价单、销售开单和现有订单互不替代。报价单不自动创建订单，销售开单不自动改变订单状态；报价单只有在用户手动标记为“已成交”后，才允许复制为一张新的销售开单。

## 已确认的业务规则

### 1. 模块边界

- 侧边栏分别增加“报价单”和“销售开单”两个入口。
- 报价单和销售开单有各自的列表、编辑器、编号规则、状态、删除、复制和 PDF 导出操作。
- 两个模块共享产品库选择器、历史客户建议、公司资料设置、金额计算和图片处理基础能力，但不共享业务单据表或单据状态。
- 从报价单复制销售开单时复制数据快照，后续修改销售开单不影响报价单；报价单也不反向更新销售开单。
- 临时产品只保存到当前报价单或销售开单，不自动写入系统产品库。

### 2. 报价单

#### 2.1 编号与状态

- 系统自动生成报价单号：`BJYYYYMMDD###`，按日期递增。
- 编号不可手动修改，报价单和销售单分别使用自己的流水序列。
- 状态为：`草稿`、`已发送`、`已成交`、`已失效`。
- 状态由用户手动切换，不因保存或导出 PDF 自动变化。
- 只有状态为“已成交”的报价单显示“复制为销售开单”操作。

#### 2.2 顶部与底部字段

默认字段：

- 公司名称
- 报价单号
- 报价日期
- 客户名称
- 联系人
- 联系电话
- 有效期
- 备注
- 不含税合计
- 税率
- 税额
- 含税合计

公司 Logo、公司电话、公司地址由设置提供，并可在每张报价单中分别选择是否显示。顶部/底部允许增加自定义字段，字段名称和值均由用户填写。客户名称、联系人、联系电话和地址输入时提供历史报价单与销售开单的建议，选择建议后仍可修改。

#### 2.3 产品明细

- 产品来源为系统产品库。
- 产品选择支持按品名、SKU、规格筛选。
- 添加产品后默认带入产品第一张图片、品名、SKU、规格。
- 若产品有多张图片，当前报价单可以切换使用其他图片；切换只影响当前单据。
- 产品库没有的产品可以在报价单中添加临时产品，至少填写品名；临时产品可上传当前单据使用的图片。
- 支持多行产品，同一产品可以重复添加为不同报价行。
- 每行产品默认可编辑数量、单价、备注，并按当前单据列配置显示/隐藏：图片、品名、SKU、规格、数量、单价、金额、备注。
- 金额由数量乘以单价计算，数量和价格必须是非负数；参与报价合计的产品行金额不能为负数。

#### 2.4 税费

- 默认按不含税报价。
- 单张报价单可填写一个统一税率，税率默认为 0。
- 系统计算不含税合计、税额和含税合计。
- 税率、税额和含税合计可以在本张报价单中选择是否显示。

#### 2.5 PDF

- 导出格式为 A4 纵向 PDF。
- 产品图片显示在产品名称左侧的独立列中。
- 产品较多时自动分页，每页重复产品表头。
- PDF 只渲染本张报价单保存的字段显示配置和快照，不读取当前产品库或当前公司设置覆盖历史内容。
- 导出失败时保留报价单数据，不改变报价单状态，并向用户显示可读错误。

### 3. 销售开单

#### 3.1 编号与状态

- 系统自动生成销售单号：`XSYYYYMMDD###`，按日期递增。
- 编号不可手动修改。
- 单据状态为：`草稿`、`已开单`、`已作废`，由用户手动切换。
- 付款状态独立计算为：`未付款`、`部分付款`、`已付清`，不可手动覆盖。
- 复制报价单时创建新的销售单号，初始单据状态为“草稿”，已收金额为 0。

#### 3.2 单据字段

默认字段和图片示例保持一致：

- 公司名称
- 客户
- 地址
- 日期
- 采购单号
- 产品代码
- 产品名称
- 数量（PCS）
- 不含税单价
- 不含税金额
- 备注
- 运费
- 不含税合计
- 税率
- 税额
- 含税合计
- 未付款合计（中文大写和数字）
- 开单人
- 收货人

公司 Logo、公司电话和公司地址由设置提供，销售单可单独选择是否显示。开单人默认读取设置中的默认开单人，但每张销售单可以临时修改。

#### 3.3 产品明细

- 支持按品名、SKU、规格筛选系统产品库并调用产品信息。
- 支持添加当前销售单专用的临时产品；临时产品至少填写产品名称，可以填写产品代码、规格和备注，并可上传图片。
- 支持多行产品。
- 每行填写或修改数量、单价和备注。
- 运费使用独立行或专用金额字段参与合计，不作为系统产品库产品保存。
- 默认 PDF 不显示图片；本张销售单可以打开“显示产品图片”配置。打开后使用当前单据中各产品保存的图片快照。

#### 3.4 税费与金额

- 默认按不含税金额计算。
- 单张销售单使用一个统一税率，默认 0。
- 自动计算不含税合计、税额和含税合计。
- 未付款金额 = 含税合计 - 所有有效收款记录金额，结果不允许小于 0。
- 收款金额超过应付金额时拒绝保存，显示明确错误。
- 中文大写金额根据未付款金额计算，金额保留两位小数。

#### 3.5 收款记录与付款凭证

每张销售单支持多笔收款，每笔记录：

- 收款日期
- 收款金额
- 付款方式
- 备注，例如“预付款”“尾款”
- 可选付款凭证图片

付款凭证支持文件上传和 `Ctrl+V` 粘贴图片。凭证保存为销售单独立附件，不复用订单付款凭证。删除收款记录时同步删除其专属附件；保存失败时不留下孤立附件。

#### 3.6 PDF

- 导出格式为 A4 纵向 PDF。
- 默认采用图片示例中的紧凑表格样式，不显示产品图片。
- 本张销售单开启图片列后，PDF 才显示产品图片。
- 产品较多时自动分页，每页重复表头。
- PDF 包含客户、地址、日期、采购单号、产品明细、运费、合计、未付款金额大写、开单人和收货人等已启用字段。
- 导出失败不改变销售单状态和付款记录。

### 4. 设置与历史建议

设置中新增或扩展以下公司资料：

- 公司名称
- 公司 Logo
- 公司电话
- 公司地址
- 默认开单人

报价单和销售开单创建时读取默认值，保存时写入单据快照；单据编辑时可临时修改显示内容。历史客户建议从两类单据的已保存客户字段聚合得到，不建立独立客户表。

### 5. 数据模型边界

新增独立表，不使用通用 JSON 单据表：

- `quotations`：报价单主表、状态、客户信息、编号、税率、合计、字段显示配置和公司资料快照。
- `quotation_items`：报价产品行快照、图片快照、数量、单价、金额、备注和排序。
- `quotation_custom_fields`：报价单自定义字段。
- `sales_documents`：销售单主表、状态、客户信息、编号、税率、合计、显示配置和公司资料快照。
- `sales_document_items`：销售产品行快照，包含产品库引用可选值和临时产品标记。
- `sales_receipts`：收款记录、付款方式、备注、金额和日期。
- `sales_receipt_files`：销售单收款凭证附件。
- `document_number_sequences`：报价单和销售单按日期递增的编号序列。

产品库引用只用于选择时定位产品；历史单据必须保存产品名称、SKU、规格、图片相对路径/文件快照等展示数据，产品库删除或修改不影响历史单据。

### 6. 页面与接口边界

前端新增：

- `QuotationPage`：报价单列表、状态筛选、新建/编辑、复制、删除、导出。
- `SalesDocumentsPage`：销售单列表、付款筛选、新建/编辑、从报价单复制、删除、作废、导出。
- `QuotationForm`：报价单字段、产品选择、临时产品、列配置和金额计算。
- `SalesDocumentForm`：销售单字段、产品选择、临时产品、收款记录、凭证粘贴和金额计算。
- 可复用的产品库选择器、客户建议输入、公司资料读取和 PDF 文档预览/导出能力。

后端新增独立路由：

- `/api/quotations`
- `/api/quotations/:id`
- `/api/quotations/:id/pdf`
- `/api/quotations/:id/copy-to-sales`
- `/api/sales-documents`
- `/api/sales-documents/:id`
- `/api/sales-documents/:id/pdf`
- `/api/sales-documents/:id/receipts`
- `/api/sales-receipts/:id`
- `/api/document-customers/suggestions`

所有保存接口使用事务。编号生成、主表、明细、显示配置、快照和收款记录必须在一个明确的业务边界内完成；错误响应沿用现有 `{ code, message, field? }` 格式。

### 7. 错误处理

- 产品行为空、数量/单价格式错误、税率小于 0、收款金额小于 0或超出应付金额时拒绝保存。
- 报价单或销售单没有任何有效产品行时不能导出 PDF。
- 删除已不存在的单据返回可读的“记录不存在”，不影响其他数据。
- 删除已成交报价单或已开单销售单前要求二次确认；已作废销售单仍保留历史，不做物理删除。
- 文件格式、大小不符合现有图片限制时拒绝上传并清理临时文件。
- PDF 生成失败时记录服务端错误日志，并保留可再次尝试的单据草稿。

### 8. 测试与验收标准

后端/单元测试覆盖：

- 报价单号和销售单号按日期独立递增，跨日期重新从 001 开始。
- 报价单多行产品、列配置、税率和金额计算。
- 报价单保存产品与图片快照，产品库修改后历史报价内容不变。
- 非“已成交”报价单不能复制销售单；复制后产生独立销售单号和独立数据。
- 销售单可添加系统产品和临时产品，产品库不存在的临时产品不写入产品库。
- 收款记录累计、付款状态、未付款数字金额和中文大写金额计算。
- 收款金额超额、负数数量/单价、空产品行和税率非法值被拒绝。
- 收款凭证上传、Ctrl+V 粘贴、删除记录时附件清理。
- 公司资料和列配置快照不随设置修改变化。

前端验收覆盖：

- 两个模块各自独立新建、保存、编辑、筛选和删除。
- 报价单可调用系统产品、切换图片、添加临时产品、配置显示列并导出 A4 PDF。
- 已成交报价单可复制为销售单，复制结果默认草稿且已收金额为 0。
- 销售单可切换产品图片显示、录入多笔收款、粘贴凭证并导出 PDF。
- A4 纵向 PDF 无内容截断，产品多页时表头重复，默认销售单不显示图片。
- 现有订单、箱唛、备货、打包和发货流程回归测试继续通过。

## 不在本次范围内

- 独立客户主数据表。
- 报价单自动生成订单或自动改变订单状态。
- 销售开单自动改变订单发货状态。
- 云端同步、多人协作和权限系统。
- 复杂的多税率产品级税务规则。
- 自动读取银行流水或自动核销收款。
