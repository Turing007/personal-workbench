## 2. 目标与范围

### 2.1 目标

将现有 Electron 桌面版重做为轻量本机网页版，减少应用外壳和无效界面占用，同时保留已确认的订单工作流：

```text
新建订单 → 打印箱唛 → 待备货 → 已备货 → 待打包 → 待发货 → 已发货
```

其中：

- “已备货”表示已经向供应商报货，不代表已打包。
- 货物拿回后，用户手动将订单推进为“待打包”。
- 打包完成后，用户手动将订单推进为“待发货”。
- 回填物流单号并确认发货后，订单变为“已发货”。

### 2.2 第一版包含

1. 产品库
2. 客户产品库
3. 订单管理
4. 订单内箱唛编辑与跨订单批量打印
5. 发货管理与发货批次
6. 设置中的一键备份和恢复
7. 产品图片和付款凭证文件保存

### 2.3 第一版不包含

- 桌面版历史数据自动迁移
- 登录、账号、角色和权限
- 局域网或公网访问
- 供应商备货表和客户产品与系统产品的正式对应流程
- PDF 导出流程
- 自动开机运行
- 独立的工作台首页
- 独立的打印历史导航入口

打印历史仍会记录，但从订单管理或箱唛批量打印流程中查看。

## 3. 用户界面结构

### 3.1 总体布局

采用已确认的 **A：紧凑侧边栏**：

- 左侧固定窄导航栏。
- 右侧为当前工作区。
- 品牌名称显示为“个人工作台”。
- 不显示桌面版标识。
- 启动后默认进入“订单管理”。
- 导航入口按以下顺序排列：
  - 订单管理
  - 产品库
  - 客户产品库
  - 发货管理
  - 设置
- 不单独显示“箱唛打印”入口，箱唛打印直接在订单管理中完成。
- 不单独显示“打印队列”和“新建订单”顶部冗余入口；新建订单按钮只保留在订单管理工具栏。

### 3.2 订单管理工作区

采用已确认的 **列表优先**布局：

- 页面标题与状态统计保持紧凑。
- 订单状态卡在一行显示，并可点击筛选订单。
- 状态卡固定包含以下 7 项：
  - 全部

  - 待备货
  - 已备货
  - 待打包
  - 待发货
  - 已发货
- 搜索支持订单号、客户来源、收件人、品名、SKU、规格。
- 订单列表支持多选。
- 批量操作固定包含：批量打印箱唛、批量推进状态、加入发货批次。
- 查看订单详情使用紧凑弹窗，不跳转独立页面。
- 箱唛编辑和打印历史从订单行操作或批量打印入口打开。

订单列表字段：

| 字段 | 说明 |
| --- | --- |
| 选择框 | 支持批量操作 |
| 订单号 | 用户手动填写 |
| 下单时间 | 订单创建时间 |
| 客户来源 | 例如“微信 - 客户名称” |

| 总箱数 | 根据订单装箱方案计算 |

## 4. 产品与订单录入设计

### 4.1 产品库

产品库保存系统产品基础信息，字段包括：

- 品名
- SKU
- 分类
- 采购价
- 供应商
- 规格参数
- 颜色，多选；默认颜色包含蓝、红、黄，并支持自定义
- 电池插脚，多选；预置牧田、德伟、米沃奇，并支持扩展
- 多种包装方式，每种包装方式单独一行
- 每种包装方式的包装名称
- 每种包装方式对应的外箱长、宽、高
- 每种包装方式对应的外箱重量
- 每种包装方式对应的装箱数
- 产品图片，可上传和预览
- 配件与备注

同一品名但规格不同，视为不同产品记录。SKU、品名和规格的组合用于订单内产品识别和筛选。

产品库页面保持紧凑：编辑区显示品名、SKU、规格和装箱数四个核心字段，操作按钮固定为添加、修改、删除、清空；图片、包装和扩展字段在同一编辑弹窗中维护，不额外占用主导航。

### 4.2 客户产品库

客户产品库是订单录入使用的统一产品库，与系统产品库保持独立。第一版不要求二者自动打通，也不要求在录单时同步系统产品信息。

客户产品字段包括：

- 品名
- SKU
- 规格
- 包装方式列表；每种包装方式包含包装名称、外箱尺寸、外箱重量和装箱数
- 备注

产品选择页面采用已确认的 **C：左右分栏选择**：

- 左侧：按品名、SKU、规格筛选客户产品库。
- 左侧支持直接添加新品。
- 右侧：显示已选产品、订单数量和自动箱数。
- 支持在同一订单中添加多行产品。
- 添加后保留产品名称、SKU、规格和装箱方案快照，避免后续产品库修改影响历史订单。

### 4.3 新建订单

采用已确认的 **B：基础信息 + 产品区**布局，订单基础信息和产品明细分区显示。

订单字段：

- 订单号：用户手动填写，允许直接使用用户习惯的格式
- 下单时间
- 客户来源：保存来源类型和来源名称，例如“微信 - 华南五金”；来源名称用于检索订单，不显示在箱唛
- 收件信息：单个多行文本框，保存收件人、地址、电话和其他补充文字
- 收件人名称：从收件信息中单独维护或由用户填写，用于箱唛；箱唛只显示这个名称
- 订单金额
- 发货单号：可在发货阶段回填
- 付款凭证：支持上传多张图片，并支持在付款凭证区域使用 `Ctrl+V` 粘贴剪贴板图片
- 每张付款凭证下方都有独立备注输入框，记录“预付款”“尾款”等付款阶段说明；凭证和备注一起保存、编辑和删除
- 订单备注
- 订单产品明细，多行

产品明细字段：

- 客户产品引用，可为空
- 品名
- SKU
- 规格
- 装箱数或装箱方案
- 订购数量
- 自动计算箱数
- 行备注

产品库没有匹配项时，用户可以在产品选择区域直接添加新品，添加完成后继续回到当前订单。

### 4.4 自动装箱

系统根据每个产品的总数量和可用装箱数自动生成箱唛方案：

- 优先使用较大的装箱数，减少箱数。
- 不足整箱时生成尾箱。
- 尾箱数量必须准确反映当前箱实际数量。
- 多行产品分别计算装箱方案，再合并为订单箱列表。
- 订单箱列表中的每个箱保存独立内容快照。
- 用户可以启用手动合箱，将多个尾箱或指定箱合并，并重新计算箱号和总箱数。
- 用户可以在打印前逐箱修改内容。
- 逐箱修改后，系统保留手动修改标记，除非用户主动选择“恢复自动方案”。

## 5. 箱唛设计与打印

### 5.1 打印流程

箱唛打印直接放在订单管理内：

1. 在订单列表勾选多个订单。
2. 点击“批量打印箱唛”。
3. 系统根据订单箱列表生成批量打印工作区。
4. 用户按订单和箱号检查箱唛。
5. 用户可以逐箱编辑或恢复自动方案。
6. 点击打印，调用浏览器打印预览。
7. 用户在浏览器打印窗口中选择打印机。
8. 对于首次打印且当前状态为“待打印箱唛”的订单，生成打印预览后自动推进为“待备货”；重打已存在箱唛的订单只记录打印历史，不改变订单状态。

批量打印只允许选择当前状态为“待打印箱唛”的订单；订单若已进入后续状态，仍可从订单详情进入箱唛编辑并单独重打，不回退状态。

### 5.2 箱唛固定规格

- 页面尺寸：`10 cm × 10 cm`
- 白底、黑色边框
- 适配浏览器打印预览
- 不提供第一版 PDF 导出按钮
- 打印样式与页面其他 CSS 隔离，避免浏览器默认边距和页面内容影响标签尺寸

### 5.3 箱唛字段和版式

参考用户提供的箱唛图片，标签内容为：

顶部：

- `箱 唛 / BOX LABEL`
- 分隔线

中部：

- `收件人：` + 收件人名称
- `订单号：` + 用户手动填写的订单号
- 大号显示：`当前箱号 / 总箱数`

下部表格：

| SKU | 品名 | 规格 | 装箱数 | 箱数 | 总数 |
| --- | --- | --- | --- | --- | --- |

表格内容来自当前箱实际装箱结果，不使用整单汇总替代当前箱内容。

底部右侧显示打印日期。

箱唛禁止显示：

- 客户来源
- 联系电话
- 收货地址
- 订单金额
- 付款凭证
- 内部备注

### 5.4 打印历史

每次批量打印记录：

- 打印时间
- 订单列表
- 每个订单的箱唛数量
- 箱号范围
- 打印动作类型
- 打印时的箱唛内容快照

打印历史在订单详情或批量打印工作区查看，不单独占用侧边栏入口。

## 6. 发货管理

采用已确认的 **A+B 组合**：

- A：左侧按待发货、已发货、全部订单筛选，并显示可加入批次的待发货订单。
- B：右侧维护当前发货批次，显示批次订单、总箱数、物流单号回填状态和发货表。

### 6.1 发货批次

- 只有状态为“待发货”的订单可以加入批次。
- 支持多选订单加入当前批次。
- 批次显示批次编号、订单数和总箱数。
- 支持保存草稿批次、清空批次、复制发货表。
- 第一版只需要一个当前工作批次，不设计复杂的批次历史管理界面；已完成批次仍通过订单状态和发货记录查询。

### 6.2 发货表

发货表严格只包含：

```text
总箱数 + 收件信息
```

示例：

```text
6箱 张三 / 广东省广州市天河区...
3箱 李四 / 浙江省宁波市...
```

不包含订单金额、产品明细、客户来源、付款信息和内部备注。支持一键复制文本，方便发送给物流商。

### 6.3 物流单号和状态

- 每个订单逐单回填物流单号。
- 物流单号为空时，不能确认该订单已发货。
- 批次内所有订单都有物流单号后，才能点击“确认批次发货”。
- 确认后批次内订单统一变为“已发货”，同时写入发货记录。
- 发货记录保存订单号、物流单号、发货时间、箱数、收件信息和备注。

### 7.2 SQLite 表

数据库包含以下表：

- `products`

- `product_images`

- `order_items`

### 7.3 文件保存

目录按用途分开：

```text
data/
  workbench.sqlite
  files/
    product-images/
    payment-proofs/
  backups/
```

上传文件先写入临时文件，校验成功后移动到目标目录；文件名使用生成的安全标识，数据库保存原始显示名称。只允许图片类型的产品图片和付款凭证，限制单文件大小，并在删除记录时同步删除孤立文件。

### 7.4 备份和恢复

设置中提供：

- 创建备份
- 选择备份文件恢复
- 恢复前预览数据数量
- 恢复前自动生成当前数据备份
- 恢复完成后刷新页面

备份包包含：

- SQLite 数据库数据
- 产品图片
- 付款凭证
- 备份格式版本
- 导出时间

恢复必须先校验备份格式、版本、数据库记录和文件路径，失败时保留当前数据不变，并返回明确错误。

## 9. 状态和错误处理

### 9.1 状态推进

允许的主流程推进：

```text
待打印箱唛 → 待备货 → 已备货 → 待打包 → 待发货 → 已发货
```

规则：

- 首次生成箱唛打印预览后，订单才允许从“待打印箱唛”推进到“待备货”；仅编辑箱唛不推进状态。
- 点击“已备货”只表示已经报给供应商，不自动变为待打包或待发货。
- “待打包”和“待发货”必须由用户手动推进。
- 已发货订单需要物流单号。
- 已取消订单不进入发货批次。
- 对不允许的状态操作返回可理解的提示，并保持原状态。

### 9.2 常见错误

- 订单号为空或重复：阻止保存并定位输入框。
- 订单没有产品明细：阻止保存。
- 数量不是正整数：阻止保存。
- 产品筛选无结果：提供添加新品入口。
- 图片格式或大小不符合要求：提示原因，不写入数据库。
- 批量打印没有选择订单：提示至少选择一条。
- 发货批次包含物流单号为空的订单：阻止确认并列出订单号。
- 备份文件损坏或版本不支持：不改变当前数据。
- SQLite 或文件写入失败：事务回滚，并显示可操作的错误信息。

## 10. 启动和停止

### 10.1 开发启动

提供标准脚本用于开发：

- `npm run dev`：启动前后端开发服务并打开网页
- `npm run build`：构建前端和后端
- `npm run typecheck`：类型检查
- `npm test`：运行自动化测试

### 10.2 用户启动

提供 `启动个人工作台.bat`：

1. 检查 Node.js 运行环境。
2. 检查端口是否已被当前项目占用。
3. 启动本机 Node 服务。
4. 等待健康检查通过。
5. 自动打开默认浏览器的订单管理页面。
6. 关闭启动窗口时，不强制终止已有数据写入；服务可按实现方案继续运行或在安全退出后停止。

启动失败必须显示明确原因，例如 Node.js 未安装、端口被占用、数据库无法打开或文件目录无权限。

### 11.2 接口测试

- 产品和客户产品的增删改查。
- 多行产品订单的事务保存。
- 付款凭证上传和删除。
- 批量箱唛打印历史写入。
- 发货批次创建、复制文本、回填物流单号和确认发货。
- 备份预览、自动备份、恢复失败回滚。

### 11.3 页面验收

- 双击启动文件后，浏览器打开订单管理。
- 状态卡保持一行并能筛选订单。
- 订单详情以弹窗显示，不跳转页面。
- 订单管理内可多选订单批量打印箱唛。
- 新建订单支持多行产品和左右分栏产品选择。
- 产品库没有产品时可直接添加新品。
- 箱唛与参考图片结构一致，打印尺寸为 10×10 cm。
- 箱唛不显示客户来源、电话和地址。
- 发货批次可生成并复制“总箱数 + 收件信息”。
- 未回填物流单号时不能确认发货。
- 备货状态和打包、待发货状态分开手动维护。
- 备份能够包含并恢复数据库、产品图片和付款凭证。

### 11.4 浏览器检查

至少检查：

- 桌面宽屏订单列表密度和弹窗显示。
- 10×10 cm 标签打印预览尺寸。
- 产品左右分栏在常用窗口宽度下不重叠。
- 发货批次表格和复制内容不截断关键字段。
- 图片粘贴、上传失败和空数据状态。

## 12. 实施顺序建议

1. 创建独立网页版工程和 Node 启动脚本。
2. 初始化 SQLite 数据库和文件目录。
3. 实现产品库与客户产品库。
4. 实现订单创建、产品选择、自动装箱和状态流转。
5. 实现订单列表、状态卡筛选、详情弹窗和批量操作。
6. 实现箱唛编辑、逐箱修改、手动合箱和浏览器打印。
7. 实现发货批次、发货表、物流单号回填和确认发货。
8. 实现备份恢复、图片和付款凭证管理。
9. 完成端到端测试和启动脚本验证。

## 13. 决策记录

- 部署：本机浏览器访问。
- 数据：新建空库，不迁移桌面版数据。
- 存储：SQLite；附件保存于项目目录。
- 权限：第一版单用户、无登录。
- 打印：浏览器预览后直接打印，不增加 PDF 流程。
- 主布局：紧凑侧边栏。
- 默认页面：订单管理。
- 订单工作区：列表优先。
- 新建订单：基础信息 + 产品区。
- 产品选择：左右分栏。
- 箱唛：跨订单批量打印，参考用户提供的 10×10 cm 标签。
- 箱唛内容：按当前箱实际内容显示，自动生成后可逐箱修改。
- 发货：待发货列表 + 发货批次工作台。
- 备份：第一版提供完整备份和恢复。
